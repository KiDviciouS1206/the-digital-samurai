# The Digital Samurai Productions

Clean cyberpunk-samurai graphic design website.

## Live
Once uploaded to the root of the GitHub repo:
https://KiDviciouS1206.github.io/the-digital-samurai/

## Upload Instructions (Important)
1. Delete everything currently in the repo (including the old digital-samurai-website folder).
2. Upload the contents of this folder **directly** to the root of the repository:
   - index.html
   - styles.css
   - script.js
   - README.md
   - assets/ folder
3. Go to Settings → Pages → Deploy from branch → main / (root) → Save.

Do NOT upload this folder inside another folder.
