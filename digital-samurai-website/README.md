# The Digital Samurai Productions — Website

A modern, cyber-samurai themed one-page website built for your Thumbtack graphic design business.

## Features

- **Full responsive design** — looks sharp on desktop, tablet, and mobile
- **Digital Samurai aesthetic** — neon cyan + crimson, circuit katana motifs, futuristic typography
- **Sections**: Hero, Services (6 offerings), Portfolio, About, Contact
- **Ready for Thumbtack** — clear phone CTA, professional presentation
- **Lightweight** — pure HTML/CSS/JS, no frameworks required

## How to Use / Deploy

### Option 1: GitHub Pages (Recommended — Free)

1. Create a new repository on GitHub (e.g. `digital-samurai` or use an existing one)
2. Upload the entire contents of this folder (`index.html`, `styles.css`, `script.js`, and the `assets/` folder)
3. Go to **Settings → Pages** → Source: Deploy from a branch → main / root
4. Your site will be live at `https://yourusername.github.io/repo-name/`

You already have experience with GitHub Pages (puckcooks), so this should be straightforward.

### Option 2: Custom Domain

Point any domain you own to the GitHub Pages site (or any static host like Netlify, Vercel, Cloudflare Pages).

### Option 3: Quick Local Preview

Just open `index.html` in a browser. Some features (fonts, etc.) need internet.
